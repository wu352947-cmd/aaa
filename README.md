# 连江一中数字校园

福建省连江第一中学（创办于 1923 年）的 3D 数字校园复刻，浏览器打开即可漫游。

## 还原依据

- 用户提供的 7 张照片：钟楼教学楼（状元楼）、弧形阳台楼、黄色主楼、天文台楼、新校区鸟瞰效果图、老校区全景照片。
- 学校官网（fjljyz.cn）首页横幅实拍：笃行楼正立面、升旗台与天文台、古榕与田径场、看台主席台、艺体馆玻璃幕墙。
- 学校简介中的功能分区：南面运动区（400 米跑道、篮球场、艺体馆），中部教学办公区（笃行楼、躬行楼、致远楼、状元楼等），北面生活区（宁逸楼、静逸楼）。

总平面以鸟瞰效果图为准，各单体的尺度与细节按实拍还原。

## 技术栈

| 层 | 选型 |
|---|---|
| 渲染 | Three.js r169 + React Three Fiber + drei |
| 建模 | 全参数化程序建模，零外部模型与贴图文件 |
| 材质 | PBR；立面贴图由 Canvas 程序绘制，同时生成基础色、粗糙度/金属度和夜景亮灯三套贴图 |
| 光照 | 自定义渐变天空 + 体积云 + 星空，天空实时烘焙为环境反射；4096 阴影贴图 |
| 后期 | N8AO 环境光遮蔽、Bloom 泛光、AgX 色调映射、SMAA、暗角 |
| 植被 | 实例化渲染的香樟、古榕（含气根）、棕榈、柏树、修剪球，叶片随风摆动 |

## 功能

- 晴日 / 黄昏 / 夜景三种时段平滑切换，夜间窗户、路灯、球场灯亮起
- 点击建筑或右侧名录，相机飞往对应视点并显示介绍
- 自动导览、楼名标签开关、高画质 / 流畅模式切换

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
```
