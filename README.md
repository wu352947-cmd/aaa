# 雾夜1888

以福建省连江第一中学 3D 数字校园为舞台的第一人称恐怖逃脱游戏。午夜的校园被血月与浓雾笼罩，开膛手杰克（Jack the Ripper，1888 年伦敦白教堂连环杀手）在雾中游荡。找齐 6 封染血的信，从东门逃出去。

故事纯属虚构。

## 玩法

| 操作 | 键鼠 | 触屏 |
|---|---|---|
| 移动 | W A S D / 方向键 | 左下摇杆 |
| 环顾 | 鼠标（点击画面锁定指针） | 右半屏拖动 |
| 奔跑 | Shift（消耗体力） | “跑”按钮 |
| 手电筒 | F | “灯”按钮 |

- 靠近信件自动拾取；每封信都会触发一段灵异事件，杀手也会变得更凶。
- 杀手看得见手电光、听得见奔跑声，近距离会直接发现你。脱离视线一段时间后他会转为搜索。
- 他会在你看不见的时候出现在身后。
- 手电电量会耗尽，拾取信件可以恢复一些。
- 集齐 6 封后东门铁栅打开，跑出校门即逃脱。

## 恐怖设计

- **氛围**：血月、浓雾、整片断电与路灯闪烁、窗内忽明忽暗。
- **杀手**：开膛手杰克的形象为高礼帽、黑披风、惨白面孔、红光双眼和手术刀。远处若隐若现，追逐时偶尔“掉帧”跳动，抓住玩家时贴脸惊吓。
- **幽灵**：白衣长发的女学生幽灵，靠近或盯着看会伴随低语消失。
- **剧情事件**：钟楼敲响第十三下、广播里的人声、探照灯爆闪照出操场中央的人影、墙上逐渐浮现的血字、走调的八音盒。
- **画面**：胶片噪点、随恐惧加剧的色差、惊吓时的画面撕裂、心跳红晕。
- **音效**：全部由 Web Audio 实时合成，包括低鸣、风声、心跳、脚步、低语、钟声、广播杂音、惊吓音和尖叫。

## 技术栈

Three.js r169 + React Three Fiber + drei + postprocessing。校园全部为程序化建模，立面贴图由 Canvas 绘制，同时生成基础色、粗糙度/金属度和夜景亮灯三套贴图；植被为实例化渲染。

