# 筹码 · 首发三剧本

网页端叙事型金融策略游戏《筹码》的第一个可玩切片，对应设计文档第十五章的第一道关卡：用一个完整剧本，同时证明“价格可信”和“博弈好玩”。

- **剧本**：1995 年 2 月，上海国债期货 327 合约。五个交易日的布局期，加上一个按分钟推进的决战日。
- **可扮演的座位**：空方券商总经理、多方信托交易员、散户、空翻多的盟友（决定何时撕毁锁仓协议）、交易所值班官员（不下单，用约谈、停市、提高保证金和当晚裁决来监管）。
- **主界面**：五个核心按钮——买入 B、卖出 S、计划书 P、人脉 R、情报 I；空格暂停。

第三个剧本 **散户起义**（2021 年 1 月，纽约）：每日开高低收取自公开行情报道（拆股前价格），分钟走势为重建。美股规则卡组：没有涨跌停但有 LULD 暂停、卖空须先借券并付借券费、T 条例 50% 保证金；1 月 28 日上午券商限制买入在撮合层生效。可扮演论坛散户、做空基金经理、零佣金券商 CEO（凌晨五点决定是否限制买入）；做市商待开放。

另有新手教程剧本 **酒馆里的花**（1636–37 年荷兰哈勒姆）：没有 K 线，七个夜晚在酒馆里和六个人当面谈价、签“春天交货”的约定，经历 2 月 3 日的崩盘，最后看 2 月 24 日花商行会把远期改作期权（付 3.5% 解约）如何重新分配谁赚谁赔。可扮演投机客、球茎种植者或行会议员（不下场，看着桌边的人签约，最后在照约履行、改作期权、一律作废之间表决）。

## 运行

```bash
npm install
npm run dev      # 本地开发，打开终端里显示的地址
npm test         # 引擎验收测试 + 台词校验测试
npm run build    # 类型检查并打包到 dist/
```

## 已实现

| 设计文档章节 | 内容 |
| --- | --- |
| 五 · 市场模拟引擎 | 价格优先、时间优先的订单簿；做市商按平方根律铺设深度；累计净流量决定永久冲击、按半衰期回归历史价格（历史引力）；趋势资金在偏离过大时追涨杀跌（反身性）；散户以一条情绪曲线出现 |
| 5.2 · 引擎验收 | 四条标准均有自动化测试：零干预回放贴近史料、冲击符合平方根律、同种子可复现（动作日志重放）、规则在撮合层强制执行 |
| 四 · 市场与监管 | 1995 年规则卡组：保证金、持仓限额、逐日盯市、强制平仓、没有涨跌停；监管热度五级，只降不清零；被规则挡住时弹出规则卡 |
| 六 · 资本操作 | 市价 / 限价单、超额透支下单（黑色操作）、条件单计划书、场外拆借（灰色） |
| 七 · 人物与博弈 | 7 个化名 NPC，各有秘密目标、底线、记忆与关系值；五个社交动词（试探、交换、结盟、背叛、告发）；锁仓同盟的囚徒困境；逐笔成交里的席位线索；声望、热度、底线三条仪表 |
| 八 · 剧本 | 序幕、布局期、决战日、清算与回响四幕；关键时刻的倒计时决策；交易所当晚裁决“交易无效”；结局页与“历史上的这一天”并排对照，并给出历史偏离度 |
| 十 · 界面 | 分时 / 日线图、“真实历史”虚线（只画到当前分钟，不剧透）、持仓成本线与穿仓线、点击图表设定限价、盘口默认一档可展开五档、悬停数字有解释、全键盘操作 |
| 十一 · 美术 | 数据层与世界层分离：深色交易界面 + 纸张雕版质感的序幕、报纸与结局；红涨绿跌 / 绿涨红跌 / 色弱方案；越过底线时画面逐渐褪色 |
| 十二 · 数据 | 只使用公开报道中的少数价格点，其余为受约束的重建路径，图表与史料卡明确标注“重建” |
| 十三 · 教学 | 规则卡、术语悬浮卡、老交易员导师（可关闭）、收盘复盘把涨跌拆成“谁把价格推到了这里” |
| 十一 · 声音 | WebAudio 现场合成：交易大厅人声随成交量起落、保证金越紧心跳越快、关键时刻与强平时响钟（设置里可关） |
| 七 · 消息树 | 结局页列出你听到的每条消息：从源头到你经过了谁、在哪一环被改动，并揭晓它的真假；被你背叛的 NPC 会故意放假消息钓你 |
| 存档 | 三个剧本都自动存档，只记“种子 + 动作日志”，读档时用确定性引擎重放到存档那一刻 |
| 十四 · 架构 | 模拟核心是纯 TypeScript、无 DOM、不读系统时钟、只用带种子的随机数，可以原样搬到服务端做成绩校验 |

台词 AI 的设计（怎样让对话多变、又不让数字和历史出错）见 [docs/llm-dialogue.md](docs/llm-dialogue.md)。

## 目录

```
src/engine/        模拟核心（确定性）：订单簿、交易所规则、市场与智能体、游戏状态机、验收测试
src/scenarios/       三个剧本：s327（期货）、gme（美股）、tulip（酒馆教学，独立的小引擎）
src/llm/           台词层：OpenAI 兼容客户端、年代风格包、提示词、校验器、模板兜底
src/ui/            React 界面
docs/              设计说明
```
