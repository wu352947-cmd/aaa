# 大肥鱼 · 鲸鱼娘 3D 模型

DeepSeek 吉祥物"大肥鱼"的鲸鱼娘手办模型：一个可在浏览器里旋转查看的彩色版本，和一个可直接切片的白色树脂打印版本。

原始网格由腾讯混元 3D（多视图，1.5m 面）生成，原文件在 Release [`model-v1`](https://github.com/wu352947-cmd/aaa/releases/tag/model-v1)。本仓库是修复后的成品。

## 目录

| 路径 | 内容 |
|---|---|
| `viewer/index.html` | 3D 展示页（正面 / 侧面 / 背面 / 立体，彩色与白模切换） |
| `viewer/models/whale_maid_color.glb` | 彩色展示模型，约 45 万面，5 MB（meshopt 压缩） |
| `viewer/models/whale_maid_print_preview.glb` | 打印版的轻量预览，仅供网页显示 |
| `print/whale_maid_print.3mf` | **打印用文件**，单位 mm，Z 轴向上 |
| `print/whale_maid_print.stl.zip` | 同一模型的 STL（解压后 45 MB） |
| `reference/` | 原始三视图，以及抠图对齐后的正 / 左 / 右 / 背四视图 |
| `tools/` | 修复用到的脚本 |

## 打印参数

- 整体 90 × 90 × 119.6 mm（人物 114 mm + Ø90 × 6 mm 底座）
- 单一封闭实体，无非流形边，法线一致
- 实心体积约 150.5 cm³；省料可在切片软件里抽壳 2 mm 并开排液孔
- 97.8% 的表面壁厚 ≥ 1.0 mm，剩下的是发梢尖端和蕾丝边缘
- 建议树脂打印，为发梢、头饰、裙边和鲸尾加支撑
- 尚未切片或实体试打

## 做了哪些修复

**打印版**
- 一侧眉毛是悬空的独立小块（离额头最多约 1 mm），已嵌回额头并合并
- 删除裙子内部一圈悬空的环片（外面看不到，打印会掉）
- 裙摆、发梢等薄于 1 mm 的地方向两侧加厚，再对加厚区域做局部平滑，去掉尖端褶皱
- 减面到 90 万面，加底座，用布尔运算合并成一个实体

**彩色版**
- 原材质的高光系数是 2.0，并带一张全平的法线贴图，渲染出来像镀铬。已改成哑光（金属度 0，粗糙度 0.6），删掉无效贴图
- 按原画重新校色，头发恢复成原画的渐变蓝
- 围裙上的鲸鱼原本糊成一团，领口宝石也不清楚：把原画对应区域按正面投影烘焙回贴图
- 脸部清理：校色把肤色压成了灰蓝，额头有红色细线，下巴和脸缘有深色涂抹线。现在用干净的暖色肤色重刷脸部皮肤（保留眼睛、嘴和压在脸上的头发），按原画位置加腮红，并把 UV 接缝外圈一起刷掉，避免出现浅色接缝线。其他部位的皮肤（手、腿）也恢复了原本的暖色
- 眼睛重画：原贴图的睫毛和高光是一堆杂乱笔触。按原画风格（深蓝到亮蓝渐变虹膜、左上高光、底部浅色反光、外眼角上挑的粗睫毛）重新绘制，形状取自模型眼窝的凹陷轮廓，所以和雕刻的眼窝完全贴合（`tools/draw_eyes.py`）

## 本地查看

展示页需要通过 HTTP 打开（直接双击 html 文件无法加载模型）：

```bash
cd viewer
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
