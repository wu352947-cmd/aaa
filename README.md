# 栖湖 · 西湖湖景公寓 3D 漫游

这是一款移动端优先的 3D 网页漫游。场景是杭州西湖东岸湖滨一套六层、一梯一户的三室两厅湖景公寓，你可以操控角色在室内随意走动，也能走上露台，凭栏看西湖。

所有模型和贴图都在运行时用代码生成，没有任何外部模型或图片资源。构建产物是一个约 700 KB 的单 HTML 文件，可以离线打开。

## 运行

```bash
npm install
npm run dev        # 局域网可访问，手机连同一 Wi-Fi 打开终端里显示的地址
npm run build      # 生成 dist/index.html（单文件，可直接用手机浏览器打开）
```

## 操作

| 设备 | 移动 | 环顾 | 其它 |
| --- | --- | --- | --- |
| 手机 / 平板 | 在屏幕左侧按住拖动（虚拟摇杆，推到底为快走） | 在右侧滑动 | 靠近门扇会自动开启 |
| 电脑 | WASD / 方向键，Shift 快走 | 按住鼠标拖动 | 第三人称下可用滚轮调整距离 |

右上角各按钮的作用：

- **时段**：在雷峰夕照、湖畔夜色、晨雾、晴午之间循环切换。
- **灯光**：开关室内灯光，包括灯槽、筒灯、台灯和纸灯笼。
- **第一 / 第三人称**：切换视角。
- **景点**：显示或隐藏雷峰塔、保俶塔、三潭印月、湖心亭、苏堤、白堤、断桥等标注及其距离。
- **户型**：打开平面图，点击房间即可传送过去。
- **设置**：调整画质（流畅 / 标准 / 精致）、转向灵敏度，或进入全屏。

## 户型（约 290 ㎡，另有 22 ㎡ 湖景露台）

- **客厅**：54 ㎡，8.6 米面宽的落地窗正对西湖。房间里有水墨山水地毯、岩板圆几、大理石电视墙和窗边茶席。
- **餐厅**：岩板餐桌配八把餐椅，背墙是通顶的青瓷、青花展柜，墙上挂苏轼《饮湖上初晴后雨》对联。
- **玄关**：地面有水刀拼花，摆着山水屏风、玄关台、通顶鞋柜和全身镜，入户是一对铜门。
- **厨房**：西厨中岛，配嵌入式冰箱和蒸烤箱、烟机灶台，水槽设在窗下。
- **主卧套房**：硬包背景墙、湖景阅读角，另有步入式衣帽间和主卫。主卫里有独立浴缸、双台盆、淋浴间和壁挂马桶。
- **次卧套房**：湖景书桌和衣柜，附干湿分离的次卫。
- **书房·茶室**：花梨木茶台、一对明式圈椅、古琴，配通顶书架和窗台盆景。
- **洗衣房**：洗烘塔、水槽和晾衣杆。

## 西湖还原

公寓的落地窗朝西。相对于这个视角，主要景物的方位如下：

- **苏堤**：远处横贯南北的一条线，堤上有六座拱桥，种着桃柳。
- **雷峰塔**：在左侧（西南），位于夕照山上，八面五层，铜瓦重檐，入夜会亮灯。
- **保俶塔**：在右侧（西北），位于宝石山上，是八面七级的实心砖塔，通高 45.3 米，整体纤秀。
- **断桥和白堤**：在右前方，白堤一直通向孤山。
- **湖中三岛**：分布在湖心，分别是三潭印月（环形岛加三座石塔）、湖心亭和阮公墩。
- **远山**：南屏山、北高峰等群山层层叠叠，带有随太阳方向变化的大气雾霭。
- **近景**：楼下是湖滨步道，有垂柳、桃花、路灯、长椅和游人；近岸有荷叶，水上有手划船、画舫和游船。
- **水面**：实时镜面反射，叠加多层涟漪、菲涅尔效果和太阳波光。

## 技术栈

- [three.js](https://threejs.org/) 0.180 负责 WebGL 渲染，用 [Vite](https://vitejs.dev/) 加 `vite-plugin-singlefile` 打包成单文件。
- **PBR 材质与贴图**：所有贴图都由程序生成，包括人字拼橡木、爵士白大理石、胡桃木、布艺、水墨画、书法和书脊（见 `src/textures.js`）。
- **光照**：
  - 太阳方向光带软阴影，阴影只在时段切换或门扇移动时重绘。
  - 在客厅采集一次室内光照探针（立方体贴图转 PMREM），为室内材质提供近似的间接光和反射。
  - 墙角加了 AO 渐变带和家具接触阴影。
  - 天空采用 Preetham 模型，夜晚换成自定义星空和月亮。
  - 雾色会随视线与太阳的夹角变化。
- **移动端优化**：
  - 静态几何按材质合并，室内只需约 200 次 draw call。
  - 树木和荷叶用实例化渲染。
  - 看不到湖时，跳过整个湖景的渲染和水面反射。
  - 根据帧率自适应调整像素比。

## 目录

```
src/
  main.js        启动、时段与灯光、主循环
  layout.js      户型数据（房间、墙体、门、落地窗）
  apartment.js   墙体、地面、吊顶灯槽、落地窗、窗帘、门、露台、建筑外壳
  furniture.js   各房间家具与软装
  westlake.js    地形、苏堤白堤、古塔、岛屿、步道、船、行人
  trees.js       垂柳 / 阔叶树（叶片卡片树冠）
  water.js       湖面着色器与镜面反射
  env.js         天空、云、星空、日光与时段预设
  atmosphere.js  方向性大气雾
  player.js      移动、碰撞、相机、角色
  ui.js          触控摇杆、HUD、户型图、景点标注
```
