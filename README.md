# 巴黎圣母院 · 1482

一个可以在手机浏览器里运行的 3D 游览游戏。它按维克多·雨果《巴黎圣母院》（1831）的描写和大教堂的实测尺寸，复原了 **1482 年**的巴黎圣母院和它周围的巴黎。你可以操控角色在城里走动、进教堂、登钟楼、敲大钟，也可以切到欣赏模式，用环绕镜头和电影式漫游看建筑。

> “建筑是用石头写成的书。”——雨果

## 运行

项目不需要构建，是纯静态网页。Three.js r169 通过 importmap 从 jsDelivr CDN 加载。

```bash
# 任选一种静态服务器
npx serve .
# 或
python3 -m http.server 8080
```

然后在手机或电脑浏览器里打开 `http://<地址>/index.html`。也可以直接部署到 GitHub Pages 或其他任何静态托管服务。

## 技术栈

- **Three.js r169**（WebGL2）、ES Modules，无需打包
- 模型、纹理和声音**全部在运行时程序化生成**，仓库里没有任何外部图片或模型文件：
  - Canvas 生成的 PBR 纹理：方整石灰岩砌块（带法线贴图）、铅皮屋顶、石板瓦/陶瓦、砂岩路面、木骨架民居立面图集（夜间窗户会亮起烛光）、13 世纪彩绘玻璃、三扇玫瑰窗、门楣浮雕、墓碑地砖、比斯科内铁艺门扇
  - 静态几何体按材质合并，城市按 260 米网格分块，这样视锥剔除能起作用，移动端的绘制调用控制在约 350 次
  - 天空、太阳位置按巴黎纬度（北纬 48.85°）和季节计算；有昼夜变化、星空、月亮和雾，环境光照用 PMREM 生成
  - 塞纳河是自写着色器：程序化波纹、菲涅耳反射、太阳高光
  - WebAudio 实时合成的声音：非谐和分音的钟声、教堂里的管风琴持续音与混响、风声、河水、人声、鸟鸣
- 碰撞检测用空间网格加速（圆柱和旋转盒），可行走平台支持台阶和坡道，第三人称相机不会穿墙
- 有三档画质（流畅、均衡、精美），控制像素比、阴影、点光源数量和远景密度

## 复原内容

### 圣母院（1482 年状态）
- **西立面**：立面前的 11 级台阶（雨果特意提到，后来被抬高的地面掩埋），三座门洞（圣母门、最后审判门、圣安娜门），层层退进的拱券和拱券上的小人像，门侧的大型使徒像（1793 年被毁），门楣的三层浮雕，扶壁壁龛雕像
- **列王廊**：28 尊带彩绘镀金残迹的王像
- **玫瑰窗层**：直径 9.6 米的西玫瑰窗和立体窗棂，圣母廊上的圣母子、天使、亚当与夏娃
- **大拱廊**、双塔之间的长廊（可登临）、钟楼的尖拱百叶窗（雨果说的“石板披檐”）、塔顶平台、北塔楼梯塔
- **约 1250 年的中世纪尖塔**：八角形、镂空、铅皮包覆，1786 年被拆除。场景里没有维奥莱-勒-杜克在 19 世纪加的尖塔和“怪兽长廊”石像
- **建筑主体**：中殿、双侧廊、楼廊、高侧窗、六分/四分肋拱顶、耳堂和两扇约 13 米的玫瑰窗（北窗以蓝紫为主，南窗以红金为主）、双回廊半圆后殿、放射状礼拜堂、单跨约 15 米的飞扶壁、小尖塔、滴水兽、红门（Porte Rouge）
- **内部**：13 世纪祭坛屏（jubé）和凯旋十字架、14 世纪唱诗班彩绘围屏、雕花橡木唱诗班座椅、鹰形讲经台，主祭坛和雨果所说的“堆满圣龛与圣髑盒”的哥特祭坛（四角铜柱上有持烛天使，圣马塞尔圣髑盒），圣克里斯托夫巨像（1413 年）和还愿人的跪像，1403 年的“燕巢式”管风琴，“巴黎圣母”像和还愿烛，烛冠，节日挂毯，从高窗斜射下来的光束和浮尘
- **钟楼**：南塔橡木钟架上的大钟“玛丽”和“雅克琳”，可以敲响，卡西莫多会扑上去拉钟绳；北塔有一组小钟，墙上刻着 **ἈΝΆΓΚΗ**（雨果序言里写到的字）

### 小说里的巴黎
- 西岱岛：较小的前院广场（爱斯梅拉达和山羊佳丽在旧波斯地毯上跳舞，弗罗洛在塔顶看着），圣约翰圆堂和弃婴木床，主宫医院，圣克里斯托夫、老圣日耳曼、圣玛德莱娜等岛内教堂，议事司铎修道院，主教宫
- 桥：小桥和小夏特莱，圣母桥（1413 年的木桥，桥上有房屋），钱币兑换桥，磨坊桥和转动的水车，圣米歇尔桥
- 西岱宫：大厅、钟塔（1370 年的公共大钟）、恺撒塔和银塔、**圣礼拜堂**
- 右岸：**河滩广场**，包括柱屋、耻辱柱（雨果描写的方石台和橡木转轮）、绞刑架、河滩十字架、主显节篝火、**罗兰塔与“老鼠洞”**（窗上刻着 TU, ORA）；还有大夏特莱和屠宰场圣雅各
- 左岸大学区、腓力·奥古斯都城墙、内勒塔、图尔奈勒、圣热纳维耶芙山；远处有卢浮宫城堡、巴士底狱、蒙福孔
- 东面的牛岛和圣母岛：当时还是无人居住的草地，有牛在吃草

游戏里的“地点”面板收录了 30 多处名胜的介绍和原著引文，可以一键传送，也可以用欣赏视角观看。
