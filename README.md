# 筹码 · 首发三剧本

网页端叙事型金融策略游戏《筹码》的第一个可玩切片，对应设计文档第十五章的第一道关卡：用一个完整剧本，同时证明“价格可信”和“博弈好玩”。

- **剧本**：1995 年 2 月，上海国债期货 327 合约。五个交易日的布局期，加上一个按分钟推进的决战日。
- **可扮演的座位**：空方券商总经理、多方信托交易员、散户、空翻多的盟友、交易所监管负责人。
- **决战之后还有两夜余波**：327 停牌清算，补不上保证金的会员、穿仓的窟窿、调查组，都要有人处理。
- **主界面**：买入 B、卖出 S、计划书 P、手段 A、人脉 R、情报 I；空格暂停。

### 行动卡（手段）

每个座位手里都有一副“手段”，白色合规、灰色游走边缘、黑色违法；卡面只写它做什么、代价是什么、什么时候能用。每张卡都真的改变市场或人：

| 座位 | 手段 |
| --- | --- |
| 交易所监管负责人 | 政治资本（每晚恢复 1 点）+ 市场秩序 + 系统风险 + 六方态度。盘中：停市、风险提示、提保证金、限令只许平仓；会员监管：电话窗口指导、现场稽查（能查出借壳代持）、追保；规则：次日提保证金、压缩限额、设涨跌停板；政策：请财政部提前公告（贴息消息不再从多方流出）、召集多空协议平仓、向证监会汇报、记者吹风会（可点名）；裁决：全部有效 / 违规后无效 / 只撤透支成交；余波：风险基金垫付、注资重组、强平了结、移交司法、出台新规、建议暂停试点。结局按秩序、稳定、公平、制度和你的去向五条线算 |
| 空方券商 | 借壳分仓、股东增资、放风“贴息被否”、接受采访喊话、托关系探口风、请交易所协调协议平仓；余波：求注资、配合调查、推给交易员、销毁记录 |
| 多方信托 | 给辽北递话、媒体吹风、对倒拉抬、举报申江借壳超仓、申请护盘资金、探口风；余波：配合调查或找人压 |
| 空翻多的盟友 | 悄悄平空、与中财谈好处费、向申江表忠心、探口风；余波：赔一笔了事 |
| 散户 | 跟单大席位；余波：联名投诉被撤销的成交 |
| 行会议员（1637） | 每晚 2 点影响力：张贴告示、约定登记、一成定金、印花钱、花商集会、救济金、游说六位议员、收礼（黑）；2 月 24 日七人表决，你的提案可能被否 |
| 投机客 / 种植者（1637） | 请老板透底价、放风“阿姆斯特丹来了大买家” |
| 零佣金券商（2021） | 提前融资、100% 保证金、暂停期权开仓、半夜找清算所豁免附加费、放宽为限购、发公告；准备足了，凌晨五点可以不限制买入 |
| 做空基金（2021） | 上电视唱空、买看涨期权对冲、加价借券、串通砸盘（黑）、游说监管查论坛 |
| 论坛散户（2021） | 发帖、买价外看涨期权、转户到没限制的券商 |

### 对手动向、上级指示、案头文书、每晚选卡

- **对手动向（进度钟）**：每个关键人物的计划画成一圈格子，满格时计划落地（申江的最后一搏、辽北倒戈、中财托盘、财政部方案；灰狼回补、做市商对冲、论坛买盘、清算所押金；哈勒姆的拍卖会、科内利斯出货、议会三条规则各自的票数）。没摸清之前只看得到“他在准备什么”；当面聊、稽查、眼线之后才看得到满格时会发生什么、眼下的盘算和怎么应对。
- **上级指示**：交易所监管负责人每天早上收到严正（证监会）或陆明远（财政部）的交代——发风险提示、派员稽查、核日报、合并计算限额、落实应急措施、不许穿仓；两位上级有时互相矛盾（“别动保证金”“别放口风”）。办到加政治资本和关系，办砸扣关系，进结局档案。行会议员每晚收到市政官的交代。
- **会员日报**：监管座位每晚逐行核对会员申报的持仓。结算部汇总的买卖两列可信，其余是会员自己报的：浦江 305 的委托从申江的交易室报进来、申江保证金吃紧时少报空单、辽北准备倒戈时照抄昨天的持仓。标对了拿到证据、合并超限的部分次日减仓；冤枉人要付代价；签字放过的问题没人告诉你。
- **击鼓传花（酒馆）**：四月结账时，亏损超过家底的人只按比例还钱，而且连锁着算——欠你钱的人自己也收不回别人的欠款。交易座位的石板上标着每个人的家底；卖给家底薄的人，价钱再高，到春天也只拿得回一部分，结算表里单列“落空的钱”。
- **卖空定金（酒馆）**：手里没有球茎还要卖约，自家球茎和买进的约盖不住的那几份，每份押合约价的一成，押不起买家就不签。卖空能做多大，取决于口袋有多深。
- **大会发言（行会议员）**：表决前可以当众力主一条规则，只能说一次：本来倾向它的议员更坚定，最反感它的反而更抱紧自己那一条，市政官只在这条规则让倾家荡产的人最少时才被说动。提交的规则跟说的不一样，威望受损、写进结局。
- **每晚选卡**：每晚从这个座位的牌堆里发三张，收下一张进手牌（最多三张）。每张都能打出，也能不打、换算成本钱（监管换政治资本，交易座位换精力，酒馆里换盾或影响力）。对手的牌自己用不了：换算给得多，但替对手把事办了（申江的游说信、中财的饭局、科内利斯塞给你的约）。牌堆与发牌由种子决定，可重放。

第三个剧本 **散户起义**（2021 年 1 月，纽约）：每日开高低收取自公开行情报道（拆股前价格），分钟走势为重建。美股规则卡组：没有涨跌停但有 LULD 暂停、卖空须先借券并付借券费、T 条例 50% 保证金；1 月 28 日上午券商限制买入在撮合层生效。可扮演论坛散户、做空基金经理、零佣金券商 CEO（这一周的准备决定凌晨五点还有哪些选项）；做市商待开放。

另有新手教程剧本 **酒馆里的花**（1636–37 年荷兰哈勒姆）：没有 K 线，七个夜晚在酒馆里和六个人当面谈价、签“春天交货”的约定，经历 2 月 3 日的崩盘，最后看 2 月 24 日花商行会把远期改作期权（付 3.5% 解约）如何重新分配谁赚谁赔。可扮演投机客、球茎种植者或行会议员（不下场，但每晚都能定规矩、收税、游说；最后七位议员投票）。

## 运行

```bash
npm install
npm run dev      # 本地开发，打开终端里显示的地址
npm test         # 引擎验收测试 + 台词校验测试
npm run build    # 类型检查并打包到 dist/
```

## 已实现

| 设计文档章节 | 内容 |
| --- | --- |
| 五 · 市场模拟引擎 | 价格优先、时间优先的订单簿；做市商按平方根律铺设深度；累计净流量决定永久冲击、按半衰期回归历史价格（历史引力）；趋势资金在偏离过大时追涨杀跌（反身性）；散户以一条情绪曲线出现 |
| 5.2 · 引擎验收 | 四条标准均有自动化测试：零干预回放贴近史料、冲击符合平方根律、同种子可复现（动作日志重放）、规则在撮合层强制执行 |
| 四 · 市场与监管 | 1995 年规则卡组：保证金、持仓限额、逐日盯市、强制平仓、没有涨跌停；监管热度五级，只降不清零；被规则挡住时弹出规则卡 |
| 六 · 资本操作 | 市价 / 限价单、超额透支下单（黑色操作）、条件单计划书、场外拆借（灰色） |
| 七 · 人物与博弈 | 7 个化名 NPC，各有秘密目标、底线、记忆与关系值；五个社交动词（试探、交换、结盟、背叛、告发）；锁仓同盟的囚徒困境；逐笔成交里的席位线索；声望、热度、底线三条仪表 |
| 八 · 剧本 | 序幕、布局期、决战日、清算与回响四幕；关键时刻的倒计时决策；交易所当晚裁决“交易无效”；结局页与“历史上的这一天”并排对照，并给出历史偏离度 |
| 十 · 界面 | 分时 / 日线图、“真实历史”虚线（只画到当前分钟，不剧透）、持仓成本线与穿仓线、点击图表设定限价、盘口默认一档可展开五档、悬停数字有解释、全键盘操作 |
| 十一 · 美术 | 数据层与世界层分离。世界层全部用代码逐像素绘制（`src/pixel/`）：1637 金鹿酒馆、1995 交易大厅、2021 卧室、夜间书房（窗外是哈勒姆山墙 / 外滩与东方明珠 / 纽约楼群）、阿姆斯特丹议事厅，以及 30 位人物的像素立绘（会眨眼、说话时张嘴、按关系变表情）；每个年代一套调色板，暗部叠雕版排线，1995 加胶片颗粒。交易大厅的人数、手势和行情大板随成交量与涨跌变化，停市时整体变暗；插画里不出现任何数字。红涨绿跌 / 绿涨红跌 / 色弱方案；越过底线时画面逐渐褪色 |
| 十二 · 数据 | 只使用公开报道中的少数价格点，其余为受约束的重建路径，图表与史料卡明确标注“重建” |
| 十三 · 教学 | 规则卡、术语悬浮卡、老交易员导师（可关闭）、收盘复盘把涨跌拆成“谁把价格推到了这里” |
| 十一 · 声音 | WebAudio 现场合成：交易大厅人声随成交量起落、保证金越紧心跳越快、关键时刻与强平时响钟（设置里可关） |
| 七 · 消息树 | 结局页列出你听到的每条消息：从源头到你经过了谁、在哪一环被改动，并揭晓它的真假；被你背叛的 NPC 会故意放假消息钓你 |
| 存档 | 三个剧本都自动存档，只记“种子 + 动作日志”，读档时用确定性引擎重放到存档那一刻 |
| 十四 · 架构 | 模拟核心是纯 TypeScript、无 DOM、不读系统时钟、只用带种子的随机数，可以原样搬到服务端做成绩校验 |

平衡性：`BALANCE=20 npx vitest run src/sim` 让每个座位用五种固定打法各跑 20 个种子，结果写到 [docs/balance.md](docs/balance.md)。

台词 AI 的设计（怎样让对话多变、又不让数字和历史出错）见 [docs/llm-dialogue.md](docs/llm-dialogue.md)。

```

docs/              设计说明
```
